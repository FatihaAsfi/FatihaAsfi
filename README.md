### 🌾 SmartHarvest 360 — Desktop Application

An intelligent farming simulation application combining crop management, machine-learning-based recommendations, weather data, and agricultural market analysis.

- 🌱 Supports crop planning and farm management.
- 🤖 Uses the Weka J48 decision-tree classifier for crop and fertilizer recommendations.
- 🌦️ Integrates NASA POWER weather data with an offline fallback.
- 📊 Tracks harvest sales, revenue, expenses, profit, and return on investment.
- 📁 Supports CSV data storage and export, with optional MySQL integration.

**Technologies:** Java · JavaFX · Machine Learning · Weka · Maven · NASA POWER API · MySQL · CSV

[View Repository](https://github.com/SuYeeMyatMoe/Smart_Harvest_360_Desktop_Application)
