## 🚀 Projects I've Worked On

### 🏎️ NightRacing

A 2D endless racing game I developed using Java and JavaFX. The idea is simple: avoid traffic, collect coins, and see how high you can score as the game gets faster.

- Dodge incoming traffic and collect coins.
- Animated road movement and particle effects.
- Sound effects and keyboard controls.

**Technologies:** Java · JavaFX · Maven

[View Repository](https://github.com/FatihaAsfi/REPLACE_WITH_NIGHTRACING_REPO)

---

### 🌍 ClimateTwin

A climate-awareness application focused on environmental assessment, analysis, and simulation. This project explores how software and data can help make climate-related information easier to understand.

- Environmental assessment and climate analysis.
- Data analysis and monthly reporting.
- Exploration of machine learning for climate-related applications.

**Technologies:** Python · CustomTkinter · Machine Learning

[View Repository](https://github.com/FatihaAsfi/REPLACE_WITH_CLIMATETWIN_REPO)

---

### 🌾 SmartHarvest 360

A desktop farming application that brings together crop recommendations, weather information, and market analysis. It explores how machine learning and software development can support agricultural decision-making.

- Crop and fertilizer recommendations using a J48 decision-tree classifier.
- Weather data integration using NASA POWER.
- Harvest sales, expenses, and profit tracking.

**Technologies:** Java · JavaFX · Weka · Maven · NASA POWER API

[View Repository](https://github.com/SuYeeMyatMoe/Smart_Harvest_360_Desktop_Application)
